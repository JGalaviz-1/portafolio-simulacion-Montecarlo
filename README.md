# Portafolio de Simulación y Métodos Numéricos

Collection of 9 projects oriented to implement Montecarlo techniques to computational physics and random phenomenon.
They include source code and the PDF documenting the project.

## Proyectos
1. Monte Carlo simulation to approximate Pi
2. Paralellization of the first project
3. Implementing the Box-Mueller method to obtain a RNG with normal distribution out of the uniform RNG
4. Implements a Montecarlo simulation to compute the Radial distribution function of a mono component system of Hard spheres 
5. Parallelization of the 4th project
6. The Thomson problem is solved numerically using a Random Walk and the steepest descent
7. The Thomson problem is solved numerically using the Metropolis-Montecarlo scheme
8. An iterative Montecarlo is used to construct an ODE solver
